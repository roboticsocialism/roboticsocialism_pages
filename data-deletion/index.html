資料刪除說明 Data Deletion Instructions

本頁說明 Facebook Login／Meta Platform Data 與 Robotic Social 帳戶資料的刪除申請方式。

最後更新 / Last updated：2026-08-11

重要：在 Facebook 設定中移除本應用程式，通常會停止後續授權或存取，但不代表先前已儲存在 Robotic Social 的帳戶或個人資料會自動刪除。如需刪除本服務持有的資料，請依下列方式提出申請。

1. 如何提出刪除申請 / How to request deletion

請寄信至 waneyvin.desktop@gmail.com，主旨可註明「Robotic Social 資料刪除申請 / Data Deletion Request」。

為協助我們定位正確帳戶，請盡可能提供：

  • 您在 Robotic Social／藏家園地使用的顯示名稱；
  • 您用於 Facebook Login 或本服務帳戶的電子郵件地址（如有）；
  • 其他足以辨識帳戶的非敏感資訊，例如帳戶頁面或相關服務紀錄說明。

請不要透過一般電子郵件寄送 Facebook 密碼、access token、完整身分證件號碼或其他不必要的敏感憑證。

2. 身分核對 / Identity verification

為避免未經授權的刪除，我們可能要求您提供合理且必要的補充資訊，以確認申請人與目標帳戶的關聯。核對只會以完成刪除申請所需的程度進行。

3. 預計處理時間 / Expected timeframe

在收到足以辨識並核對帳戶的完整申請後，我們通常會於 7 個工作天內完成刪除，或回覆目前處理狀態。若因複雜資料關聯、合法保存義務或其他必要原因需要較長時間，我們會向您說明。

4. 可能刪除的資料 / Data covered

依實際帳戶與服務使用情形，刪除範圍可能包括：

  • 透過 Facebook Login 取得並儲存的 Facebook User ID、姓名、電子郵件、頭像或公開個人資料（以您實際授權／提供者為限）；
  • Robotic Social 帳戶資料、聯絡資訊與 Facebook Login 關聯資訊；
  • 您要求刪除且可合理歸屬於該帳戶的使用者提供內容與服務資料；
  • 在技術上可識別並可刪除、且不需依法或基於安全目的保留的相關紀錄。

5. 必要保存例外 / Retention exceptions

若法律、法規、有效法律程序、資安事件調查、防詐、防濫用、爭議處理或權利主張要求我們保存特定資料，我們可能在必要範圍與期間內保留該部分資料。超過必要期間後，將依適用規則刪除或去識別化。

6. 完成通知 / Completion notice

完成刪除後，我們會盡可能透過您提出申請時使用的聯絡方式通知您；若有依法或基於安全理由必須暫時保留的項目，也會在適當範圍內說明。

7. Facebook Login 與隱私政策

本刪除流程同樣適用於與 Facebook Login 相關、由 Robotic Social 實際持有的資料。關於資料蒐集、使用、分享與保存原則，請參閱 隱私權政策 / Privacy Policy。
